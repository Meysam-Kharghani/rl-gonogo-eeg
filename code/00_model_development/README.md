# Historical and stopped model-development source

These formalized historical source snapshots preserve the EEG analysis branches that preceded the canonical EEG-computational study pipeline. They document alignment correction, ERP validation, topography, exploratory decoding, entropy-candidate evaluation, and historical RL–neural association analysis development.

`deferred_extensions/` contains code-only branches that were **stopped by design** and were not promoted to the evidential hierarchy. Their presence records the project history; it does not imply that their analyses were completed or should be interpreted as missing sensitivity analyses.

Canonical feature generation and inferential analyses are located in `code/01_feature_generation/` through `code/04_robustness/`. Original historical-source SHA-256 identifiers are retained in `docs/eeg_development_source_hashes.tsv`.
