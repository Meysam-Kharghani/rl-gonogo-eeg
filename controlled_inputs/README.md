# Controlled inputs

This directory is intentionally empty in the public repository. Full model refitting requires authorized participant-level inputs that are not redistributed.

Expected controlled inputs: Behavioral trial tables, processed EEG feature tables, cross-fitted RL tables, and cross-validated RL posterior objects.

See `docs/controlled_input_schema.md` for the required fields and `docs/data_availability.md` for access boundaries. Public figure reproduction uses only aggregate files under `results/`.
