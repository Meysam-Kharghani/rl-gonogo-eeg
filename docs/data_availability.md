# Data availability

This repository excludes participant-level and identifying data.

Not distributed:

- raw EEG recordings;
- processed participant EEG (`.set/.fdt` or equivalent);
- trial-level EEG feature tables;
- participant-level behavioral/RL tables;
- participant identifiers or identifying metadata;
- participant-level response-signature tables;
- fold-specific actor–control RL posterior objects.

Included:

- analysis and reporting code;
- machine-readable analysis specifications;
- aggregate result tables;
- aggregate response-marker timing QC;
- figure source data and publication figures;
- data and provenance documentation.

Controlled-input reruns require the applicable ethics and data-access authorization. The access procedure and contact will be synchronized with the final publication metadata.
