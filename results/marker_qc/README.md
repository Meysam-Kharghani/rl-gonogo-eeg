# Aggregate response-marker timing QC

Response onset used for feature extraction was reconstructed as target onset + behavioral RT. The nearest response marker in the imported event list was used only for timing-consistency QC; the upstream matching window was ±150 ms.

- responded trials: 10,509;
- matched markers: 10,509/10,509 (100%);
- participants with responded trials and matched markers: 40/40;
- median signed discrepancy: 0.00 ms;
- median absolute discrepancy: 0.00 ms;
- 95th percentile absolute discrepancy: effectively 0 ms;
- 100% were within 4 ms.

Because the discrepancies are essentially exact, this result is described conservatively as **internal event-alignment consistency**. It is not presented as independent validation of behavioral RT accuracy or of the physiological interpretation of the response-locked signals.
